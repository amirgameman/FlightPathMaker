# Авиамаршруты: планировщик путешествий

Проект предоставляет графический интерфейс и Telegram-бота для поиска оптимальных авиамаршрутов между городами России и СНГ. Пользователи могут находить маршруты по критериям: расстояние, цена или комфорт.

## Функционал

### Основные возможности:
- Поиск маршрутов между городами
- Три критерия оптимизации:
  - Кратчайший путь (по расстоянию)
  - Самый дешевый путь (по цене)
  - Самый комфортный путь (по оценке удобства)
- Визуализация маршрутов на карте
- Подробная информация о каждом перелете:
  - Дистанция
  - Стоимость
  - Уровень комфорта

### Интерфейсы:
1. **Графическое приложение (Tkinter)**:
   - Интерактивная карта с возможностью масштабирования
   - Подсветка выбранных маршрутов
   - Детальная информация о маршрутах

2. **Telegram-бот**:
   - Пошаговый выбор параметров через кнопки
   - Генерация изображения с маршрутом
   - Текстовое описание маршрута

## Установка и запуск

### Требования:
- Python 3.7+
- Установленные библиотеки:
- pip install tkinter pillow python-telegram-bot

### Запуск Telegram-бота:

    Создайте бота через @BotFather и получите токен

    Замените BOT_TOKEN в файле bot.py на ваш токен

    Запустите бота в консоли: python bot.py

## Структура проекта

    main.py - графическое приложение на Tkinter

    bot.py - Telegram-бот

    flight_graph.json - данные о маршрутах (граф перелетов)

    city_coords.json - координаты городов для отображения на карте

## Особенности реализации

    -Используется алгоритм Дейкстры для поиска оптимальных путей

    -Рекурсивный поиск всех возможных маршрутов (DFS)

    -Поддержка кириллических символов в интерфейсе

    -Адаптивная цветовая схема

    -Масштабируемая карта с возможностью перетаскивания

## Примеры использования

    -Найти самый дешевый маршрут из Москвы в Сочи
